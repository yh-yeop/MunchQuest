# 에셋 · 외부 코드 라이선스 장부

게임에 들어가는 그림 · 글꼴 · 소리 · 외부 코드는 파일마다 출처와 라이선스를 여기에 적는다. 출처를 모르는 파일은 넣지 않는다.
학교 필터가 CDN을 막아도 되도록 외부 파일은 `vendor/`에 직접 둔다.

| 파일 | 출처 | 라이선스 | 수정 |
|---|---|---|---|
| `vendor/galmuri/Galmuri11.woff2` · `Galmuri14.woff2` | galmuri@2.40.3 (https://github.com/quiple/galmuri) | SIL Open Font License 1.1 (`vendor/galmuri/ofl.md`) | 없음. `galmuri.css`는 두 굵기만 남긴 것 |
| `vendor/peerjs.min.js` | peerjs@1.5.4 `dist/peerjs.min.js` (https://github.com/peers/peerjs) | MIT (`vendor/peerjs.LICENSE.txt`) | 없음 |
| 타일 · 캐릭터 임시 그림 (`src/render.js`) | 직접 (코드로 그림) | 이 저장소와 같음 | — |
| `icon.svg` | 직접 | 이 저장소와 같음 | — |
