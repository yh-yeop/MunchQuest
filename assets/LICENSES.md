# 에셋 라이선스 장부

게임에 들어가는 그림 · 글꼴 · 소리는 파일마다 출처와 라이선스를 여기에 적는다. 출처를 모르는 파일은 넣지 않는다.

| 파일 | 출처 | 라이선스 | 수정 |
|---|---|---|---|
| 갈무리 글꼴 (CDN: `galmuri@2.40.3`) | https://github.com/quiple/galmuri | SIL Open Font License 1.1 | 없음 |
| 타일 · 캐릭터 임시 그림 (`src/render.js`) | 직접 (코드로 그림) | 이 저장소와 같음 | — |
| `icon.svg` | 직접 | 이 저장소와 같음 | — |
