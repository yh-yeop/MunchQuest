# 결정이 필요한 것 (자동 고도화 중 모은 질문)

자동 고도화는 M1 범위 안 다듬기만 한다. 아래는 사용자가 정해 주면 이어 갈 수 있는 것들.

## 권한 · 환경
- **Plans 레포 읽기가 막혔다** (2026-11-21, 세션에 `yh-yeop/Plans` 추가가 권한 확인에서 거절됨). 그래서 기획서 원문 대신 README의 M1 설명을 기준으로 다듬었다. 기획서의 M1 손맛 기준(히트스톱 길이, 몬스터 성격 등)이 따로 있으면 이 세션에 Plans 읽기를 허락하거나 해당 부분을 붙여 주면 맞춰 고친다.

## M1 다듬기에서 생긴 질문
- **몬스터 성격 수치**: 슬라임 무리 반경 100px, 버섯 물러나기 체력 35%, 쫓을 사람 없이 5초면 몬스터 체력 회복. 회복이 "같이 사냥하던 사람이 잠깐 마을 갔다 오면 깎아 둔 몹이 다 차 있다"로 느껴질 수 있다 — 괜찮은지?
- **히트스톱은 내가 맞힌 몬스터의 그림만 멈춘다** (0.05초 · 치명타 0.09초). 화면 전체를 멈추는 방식은 여럿이 하는 게임이라 넣지 않았다.
- **세로 화면**: 지금은 "가로로 돌리면 더 크게 보여요" 안내만 한다. 세로 전용 배치(위 게임 · 아래 버튼)를 만들지?
- **움직임 줄이기**는 기기 설정(prefers-reduced-motion)을 기본값으로 따른다. 기본 끔으로 할지?
