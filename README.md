# 냠냠 원정대 (가칭)

브라우저에서 같이 사냥하는 도트 MMORPG. 메이플식으로 포털로 이어진 필드에서 남이 사냥하는 게 보이고, 하루 30분이면 할 일이 끝난다. 지금은 **M1 필드 · 손맛** 단계.
기획서: `yh-yeop/Plans` 의 `docs/2026-11-02-MMORPG-기획-냠냠-원정대.md`

👉 플레이테스트: https://yh-yeop.github.io/MunchQuest/

## 학교에서 하기 좋게

| 막히는 곳 | 대응 |
|---|---|
| 학교 와이파이는 기기끼리 직접 연결(WebRTC)을 막는 경우가 많다 | **중계 서버**(Cloudflare Workers, `wss` 443 포트)로 붙는다. 일반 HTTPS처럼 보여서 방화벽을 통과한다 |
| 필터가 CDN(jsdelivr 등)을 막을 수 있다 | 글꼴 · 라이브러리를 `vendor/`에 직접 둔다. `yh-yeop.github.io`만 열리면 된다 |
| 설치 불가, 사양 낮은 PC · 크롬북 | 설치 없음, 빌드 없음, 480×270 도트라 가볍다 |
| 쉬는 시간은 짧다 | 로그인 없이 4글자 코드 · 초대 링크로 바로 참가. 방은 서버에 있어서 만든 사람이 나가도 남는다 |

## 해 보는 법

- **친구와**: "방 만들기" → "초대 링크 복사"로 보낸다. 서버가 켜져 있으면 "채널 1 · 2 · 3"으로 바로.
- **혼자**: "혼자 테스트" — 봇 3명이 초원으로 가서 사냥하고, 내 연결에도 지연 150ms가 걸린다.
- **마을 동쪽 길 끝의 빛나는 곳**이 초원으로 가는 포털.
- 시작 화면 아래 초록 글씨가 지금 연결 방식이다: "서버 연결"이면 학교망에서도 된다.

| 동작 | 키 |
|---|---|
| 이동 | WASD · 방향키 (폰은 왼쪽을 누르고 끌기). 시작 화면 "설정"에서 바꿀 수 있다 |
| 공격 (누르고 있으면 연사, 가장 가까운 몬스터 자동 조준) | J · Space (폰은 공격 버튼) |
| 구르기 (구르는 동안 무적) | K · Shift (폰은 구르기 버튼) |
| 소리 켜고 끄기 | M |
| 디버그 | F3 · `` ` `` — 왕복 · 되맞춤 · 프레임 시간. 켠 상태에서 `1` `2` `3` `4` 가짜 지연 0 · 50 · 150 · 300ms, `P` 예측, `I` 보간, `B` 봇 추가 |
| 나가기 | Esc |

## 구조

빌드 없음. ES 모듈 그대로. **게임 규칙(`src/server.js`)은 연결 방식과 무관**해서 두 곳에서 같은 코드가 돈다.

```
              ┌── 서버 모드 (기본, src/config.js 의 SERVER_URL) ───────────────┐
브라우저 ×N ──┤   wss://…workers.dev/room/ABCD → Durable Object(방 하나) 안에서 server.js
 (Client)     └── 서버 없음 모드: 방장 브라우저 안에서 server.js
                  같은 브라우저 탭(BroadcastChannel) · 인터넷(WebRTC, PeerJS 중개)
```

| 파일 | |
|---|---|
| `src/sim.js` · `src/map.js` | 서버 · 클라이언트가 똑같이 돌리는 이동 · 구르기 · 공격 대기 · 지도 (결정적) |
| `src/data.js` | 몬스터 · 아이템 · 성장 수치 표 (밸런스는 여기만 고친다) |
| `src/server.js` | 권위 서버 (채널 하나 = 마을 · 필드 전부): 입력 검증(실제 시간 기준 입력 예산, 정상의 1.02배까지) · 몬스터 AI · 피해 · 드롭 · 경험치 · 스냅샷 |
| `src/mobs.js` | 몬스터 움직임: 슬라임 무리 · 토끼 돌진 · 버섯 포자와 물러나기 (서버만) |
| `src/client.js` | 예측 · 되맞춤 · 보간, 화면 효과용 사건 |
| `src/net/` | 연결 방식들(`ws` · `tabs` · `peer` · `local`)과 가짜 지연 |
| `src/config.js` | 중계 서버 주소 |
| `src/render.js` | 480×270 도트 렌더: 카메라 · 효과 · 이름표 · HUD |
| `src/sprites.js` · `src/tiles.js` | 캐릭터 · 몬스터 · 아이템 · 숫자 글꼴, 타일을 팔레트로 직접 찍음 |
| `src/tags.js` | 이름표 자리 잡기 (가까이 선 사람끼리 겹치면 위로 쌓음) |
| `src/sfx.js` | WebAudio 합성 효과음 (멀리서 난 소리는 작게, 400px 밖은 안 들림) |
| `src/keys.js` | 키 바꾸기 (주 키 + 늘 되는 보조 키, 겹치면 맞바꿈) |
| `src/main.js` | 화면 · 입력(키보드 · 터치) · 세션 · 설정 |
| `src/bot.js` | 혼자 테스트의 사냥 봇 (화면과 무관해서 시험에서도 그대로 씀) |
| `worker/` | Cloudflare Worker + Durable Object (출처 검사 · 메시지 크기 · 초당 60개 제한) |
| `vendor/` | 저장소에 둔 글꼴 · 라이브러리 |
| `testlib/fake.js` | 시험이 같이 쓰는 가짜 시계 · 정해진 무작위 · 바로 붙는 접속 |
| `bench/server.mjs` · `docs/PERF.md` | 서버 틱 비용 · 스냅샷 크기 측정과 기록 (30명: 틱 0.2ms 안팎, 스냅샷 618B · 몬스터는 바뀐 것만) |
| `sprites.json` · `assets/LICENSES.md` | 스프라이트 표 · 에셋 라이선스 장부 |

## 서버 (Cloudflare Workers)

```
cd worker
npm install
npx wrangler dev --port 8787        # 로컬: 페이지를 ?server=ws://127.0.0.1:8787 로 열기
npx wrangler login                  # 배포는 처음 한 번 로그인
npx wrangler deploy                 # 나온 주소(wss://munchquest.<계정>.workers.dev)를 src/config.js 에
```

무료 요금제 안에서 돌도록: 입력은 20Hz로 묶어 보내고, 방에 아무도 없으면 틱을 멈춘다. 접속을 받는 출처는 `yh-yeop.github.io`와 로컬 시험 주소뿐.

## 테스트

```
node --test
```

가짜 시계로 지연 150ms + 흔들림 30%를 걸고 무작위로 걷고 쏘고 구르고 포털을 넘은 뒤 예측 = 서버(되맞춤 0회)인지, 같이 잡으면 둘 다 경험치 + 보너스 · 드롭은 각자 것만 보이고 줍는지, 공격 입력을 쏟아부어도 발사 간격을 서버가 지키는지, 입력을 정상보다 자주 보내도 걷기 · 연사가 1.02배를 못 넘는지, 서버 틱이 늦거나 와이파이가 끊겼다 와도 정상 입력이 밀리지 않는지, 쓰러지면 마을에서 다시 시작하는지, 지도 입구 · 몬스터 자리가 막혀 있지 않은지, Worker가 출처 · 메시지 수 · 크기를 막고 닫기에 답하는지, 가까이 선 사람 이름표가 겹치지 않고 몰리면 세 줄까지만 쌓는지, 슬라임 무리 · 버섯 물러나기 · 몬스터 체력 회복, 스냅샷 크기(10명 600B 미만) · 내 정확한 몸 상태는 나에게만, 10명이 10분(12000틱) 사냥해도 서버 상태가 쌓이지 않는지, 실제 클라이언트 4명이 지연 80~200ms로 3분 동안 사냥 · 포털을 오가도 되맞춤 0회 · 클라이언트 버퍼가 그대로인지, 토끼 돌진 경고선 방향, 몬스터를 바뀐 것만 보내도 클라이언트가 보는 몬스터가 서버와 같은지, 폰 가로 화면 터치(끌기 · 두 손가락 공격 · 버튼이 체력 칸을 안 가림), 멀리서 난 소리 줄이기, 혼자 테스트의 사냥 봇 8명이 5분 동안 모두 레벨이 오르고 오래 끼지 않는지, 작은 폰(568×320)에서 누르는 크기 · 시작 상자가 화면 안인지, 키 바꾸기 등 65개. 푸시하면 GitHub Actions에서도 돈다.
Playwright가 깔려 있으면 실제 브라우저로 혼자 테스트 화면도 확인한다 (CI에선 건너뜀).

## 알려진 한계 (M1)

- 서버 주소가 비어 있으면 방장 브라우저 모드로 돌아가는데, 이때 인터넷 연결은 WebRTC 직접 연결이라 학교 · 회사망에서 실패할 수 있다.
- 레벨 · 가방은 접속 중에만 유지된다 (계정 · 저장은 M2).
- 그림은 코드로 찍은 도트라 공개 전에 다듬는다 (기획서 공개 기준).
