# 냠냠 원정대 (가칭) · 기술 검증

몬스터를 사냥해 요리하고 같이 먹고 다시 떠나는 온라인 협동 액션 RPG — 의 **기술 검증(M0)** 단계.
기획서: `yh-yeop/Plans` 의 `docs/2026-11-02-MMORPG-기획-냠냠-원정대.md`

👉 플레이테스트: https://yh-yeop.github.io/MunchQuest/

## 학교에서 하기 좋게

| 막히는 곳 | 대응 |
|---|---|
| 학교 와이파이는 기기끼리 직접 연결(WebRTC)을 막는 경우가 많다 | **중계 서버**(Cloudflare Workers, `wss` 443 포트)로 붙는다. 일반 HTTPS처럼 보여서 방화벽을 통과한다 |
| 필터가 CDN(jsdelivr 등)을 막을 수 있다 | 글꼴 · 라이브러리를 `vendor/`에 직접 둔다. `yh-yeop.github.io`만 열리면 된다 |
| 설치 불가, 사양 낮은 PC · 크롬북 | 설치 없음, 빌드 없음, 480×270 도트라 가볍다 |
| 쉬는 시간은 짧다 | 로그인 없이 4글자 코드 · 초대 링크로 바로 참가. 방은 서버에 있어서 만든 사람이 나가도 남는다 |

## M0에서 확인하는 것

| 항목 | 기준 | 상태 |
|---|---|---|
| 같은 방의 여러 명이 서로 움직이는 게 보임 | 서버 · 탭 · 인터넷(WebRTC) 모두 | ✅ |
| 내 이동은 지연이 있어도 바로 반응 (예측) | 지연 150ms에서 끊김 없음, 되맞춤 0회 | ✅ (테스트 · 실제 브라우저) |
| 다른 사람은 부드럽게 (보간) | 스냅샷 20Hz 사이를 보간 | ✅ |
| 도트가 뭉개지지 않음 | 480×270 정수 배율, 좌표 정수 | ✅ |

## 해 보는 법

- **친구와**: "방 만들기" → "초대 링크 복사"로 보낸다.
- **혼자**: "혼자 테스트" — 봇 3명이 지연 150ms로 돌아다니고, 내 연결에도 150ms가 걸린다.
- **디버그 (F3)**: 왕복 지연 · 되맞춤 횟수 · 보간 지연. `1` `2` `3` `4` = 가짜 지연 0 · 50 · 150 · 300ms, `P` 예측 끄고 켜기(끄면 지연이 그대로 느껴진다), `I` 보간 끄고 켜기, `B` 봇 추가(방장 브라우저 모드만).
- 시작 화면 아래 초록 글씨가 지금 연결 방식이다: "서버 연결"이면 학교망에서도 된다.

| 동작 | 키 |
|---|---|
| 이동 | WASD · 방향키 (폰은 화면을 누르고 끌기) |
| 디버그 | F3 · `` ` `` |
| 나가기 | Esc |

## 구조

빌드 없음. ES 모듈 그대로. **게임 규칙(`src/server.js`)은 연결 방식과 무관**해서 두 곳에서 같은 코드가 돈다.

```
              ┌── 서버 모드 (기본, src/config.js 의 SERVER_URL) ───────────────┐
브라우저 ×N ──┤   wss://…workers.dev/room/ABCD → Durable Object(방 하나) 안에서 server.js
 (Client)     └── 서버 없음 모드: 방장 브라우저 안에서 server.js
                  같은 브라우저 탭(BroadcastChannel) · 인터넷(WebRTC, PeerJS 중개)
```

| 파일 | |
|---|---|
| `src/sim.js` · `src/map.js` | 서버 · 클라이언트가 똑같이 돌리는 이동 · 충돌 · 지도 (결정적) |
| `src/server.js` | 권위 서버: 입력 검증 · 판정 · 스냅샷 |
| `src/client.js` | 예측 · 되맞춤 · 보간 |
| `src/net/` | 연결 방식들(`ws` · `tabs` · `peer` · `local`)과 가짜 지연 |
| `src/config.js` | 중계 서버 주소 |
| `src/render.js` | 480×270 도트 렌더 (지금은 팔레트로 그린 임시 그림) |
| `src/main.js` | 화면 · 입력 · 세션 |
| `worker/` | Cloudflare Worker + Durable Object (출처 검사 · 메시지 크기 · 초당 60개 제한) |
| `vendor/` | 저장소에 둔 글꼴 · 라이브러리 |
| `sprites.json` · `assets/LICENSES.md` | 스프라이트 표 · 에셋 라이선스 장부 |

## 서버 (Cloudflare Workers)

```
cd worker
npm install
npx wrangler dev --port 8787        # 로컬: 페이지를 ?server=ws://127.0.0.1:8787 로 열기
npx wrangler login                  # 배포는 처음 한 번 로그인
npx wrangler deploy                 # 나온 주소(wss://munchquest.<계정>.workers.dev)를 src/config.js 에
```

무료 요금제 안에서 돌도록: 입력은 20Hz로 묶어 보내고, 방에 아무도 없으면 틱을 멈춘다. 접속을 받는 출처는 `yh-yeop.github.io`와 로컬 시험 주소뿐.

## 테스트

```
node --test
```

가짜 시계로 지연 150ms + 흔들림 30%를 걸고 무작위로 4초 걸은 뒤 예측 위치 = 서버 위치(되맞춤 0회)인지, 벽을 뚫지 않는지, 서버가 이상한 입력을 거르는지, 타이머가 반올림돼도 메시지 순서가 안 바뀌는지 등. 푸시하면 GitHub Actions에서도 돈다.
